Тема: Детекция следов диких животных на фотографиях

Задание:
1. Выполнение финального задания:
• Подготовить инструкцию для разметчиков выбранного датасета;
• Установить систему разметки (например Label Studio);
• Выполнить разметку калибровочного датасета.
2. Оформить отчет по финальному заданию.
Цель разметки: детекция объектов на снимках.
Технические требования:
Разметка — боксами (прямоугольниками, описывающими обьект по внешним границам).
Точность границ — допустимы отклонения (2-5 пикселей от реального контура). Главное — не обрезать значимые части объекта и не захватывать посторонние элементы.
Пересекающиеся объекты — усекать границы боксов по линии соприкосновения (без наложения).
